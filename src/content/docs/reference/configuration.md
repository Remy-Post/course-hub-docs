This page lists names only. Secret values live in files with mode `600`, or in the macOS Keychain, and are never committed.

## Ports on the Mac

All ports are bound to `127.0.0.1`.

| Port | Service |
|---|---|
| `5678` | n8n editor and webhooks |
| `8080` | Caddy: the local site at `/hub`, and the API at `/hub/api/*` |
| `11434` | Ollama (native macOS app) |
| `3200` | n8n code sandbox API |
| `8888` | SearXNG (web search for the n8n Assistant) |

MongoDB (`27017`) and the task runners (`5679`) are reachable only inside the Docker network.

## Ports on the Oracle VM

| Port | Service |
|---|---|
| `3000` | The web app inside the Docker network `n8n_default`. cloudflared reaches it as `n8n-hub:3000`. |
| `127.0.0.1:3010` | The same container, published on loopback for smoke tests (`curl 127.0.0.1:3010/api/health`) |
| `80`, `443` | Caddy, serving an unrelated site. Not part of Course Hub. |

## Public hostnames

| Hostname | Tunnel runs on | Routes to | Allowed paths |
|---|---|---|---|
| `<web-host>` | Oracle VM | `http://n8n-hub:3000` | Everything |
| `<api-host>` | Mac | `http://n8n:5678` | `/webhook/hub/api/(overview\|courses\|settings\|plan\|decision\|checkin\|override\|checkup)` only, behind Cloudflare Access Service Auth |
| `<hooks-host>` | Mac | `http://n8n:5678` | The Twilio inbound-SMS webhook path only |

Anything else returns `404` at the tunnel.

## Web app environment

| Variable | Where | Purpose |
|---|---|---|
| `HUB_API_URL` | Server | Base URL ending in `/webhook/hub/api`. Required: a missing value is a hard error. |
| `CF_ACCESS_CLIENT_ID` | Server | Cloudflare Access service token id. Leave empty locally. |
| `CF_ACCESS_CLIENT_SECRET` | Server | Service token secret. Leave empty locally. |
| `TUNNEL_NETWORK` | Compose | Docker network shared with cloudflared. Default `n8n_default`. |

None of these are `NEXT_PUBLIC_*`, so none reach the browser. On the VM they live in `~/n8n-hub/.env`, which neither deploy path overwrites.

## Backend environment

The `n8n` container's environment is generated by `stack/build-stack.py`. Notable names:

| Variable | Purpose |
|---|---|
| `N8N_ENCRYPTION_KEY` | Decrypts every saved credential. **Back it up.** `n8nctl backup` copies it. |
| `N8N_RUNNERS_MODE`, `N8N_RUNNERS_AUTH_TOKEN` | External task runners |
| `N8N_RESTRICT_FILE_ACCESS_TO` | Folders n8n may read. Includes the courses folder. |
| `NODES_EXCLUDE` | Disabled nodes. Execute Command stays off; Local File Trigger is enabled. |
| `N8N_AI_MODEL_STREAM_IDLE_TIMEOUT_MS`, `N8N_AI_MODEL_STREAM_FIRST_OUTPUT_TIMEOUT_MS` | Raised to 10 and 15 minutes for slow local models |
| `N8N_WEBHOOK_URL` | Public base URL that Twilio calls back |
| `OLLAMA_HOST` | Ollama address as seen from the container |
| `GENERIC_TIMEZONE`, `TZ` | `America/Toronto` |

Secrets live in `stack/secrets.env` (`N8N_ENCRYPTION_KEY`, `N8N_RUNNERS_AUTH_TOKEN`, `MONGO_ROOT_PASSWORD`, `MONGO_APP_PASSWORD`). `build-stack.py` splits them into `stack/env/{n8n,runners,mongo}.env`.

## Ollama

`bin/ollama-env.sh` sets these at login: `OLLAMA_KEEP_ALIVE=10m`, `OLLAMA_NUM_PARALLEL=1`, `OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0` and `OLLAMA_MAX_LOADED_MODELS=1`. Together they keep one model loaded and memory under the cap.

## launchd agents on the Mac

| Label | Does |
|---|---|
| `com.remy.colima` | Starts the Colima VM, which starts the containers |
| `com.remy.n8n-watchdog` | Runs `watchdog.sh` every 5 minutes |
| `com.remy.sysmem` | Writes the memory probe every minute |
| `com.remy.keepawake` | `caffeinate -s`: no system sleep while on power |
| `com.remy.ollama-env` | Sets Ollama's environment at login |
| `com.remy.checkup` | Optional. Answers the Check up button quickly. |
| `com.remy.n8n` | **Disabled.** Native n8n, kept as the rollback target. |

## Key files

| Path | Holds |
|---|---|
| `~/.n8n-server/RUNTIME` | `docker` or `native` |
| `~/.n8n-server/stack/compose.yml`, `Caddyfile` | Generated. Edit `build-stack.py` instead. |
| `~/.n8n-files/course-hub/site/index.html` | The served local site. `deploy.sh` copies it there. |
| `~/.n8n-files/course-hub/sysmem.json`, `checkup.json` | Memory probe and health report |
| `~/n8n-backups/` | Nightly backups |
| `~/n8n-hub/` (VM) | The served web app tree and `.env` |
| `~/n8n-hub-autodeploy/` (VM) | `repo.git`, `stage/`, `lock`, `deployed`, `failed` |
